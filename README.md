# Hackathon 26 · CollegeConnectors

HackOHI/O Bridge Builder prototype — not the Apsara skincare site.

Students and professionals connect around demos, reels, matching, mentors, and portfolio scoring (including GitHub OAuth).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:4321](http://127.0.0.1:4321).

## App surfaces

- **Student:** Feed, Reels, Match, Network, Profile (major filter, GitHub portfolio score)
- **Professional:** Home, Feedback queue, Sponsors, Network, Profile
